# À faire par l'utilisateur
- [ ] Fermer Roblox Studio avant mes publications (ne jamais cliquer Publier/Enregistrer dessus pour les lieux gérés).
- [ ] Désactiver Création en équipe sur « Sortir Du Grenier ».
- [ ] « Allow Third Party Teleports » activé sur les deux expériences.
- [ ] « Enable Studio Access to API Services » activé (utile seulement en Studio).
- [ ] Obtenir dans le catalogue les 3 œufs refusés (2937230482, 147144059, 2937218888).
- [ ] Supprimer les anciennes clés API devenues inutiles (une seule clé active).
- [ ] Tester le Grenier puis Chipe-Œufs depuis roblox.com et décrire ce qui cloche.
- [ ] Jeu 1 : remplacer les scripts livrés par la session dans Studio, puis publier à la main.
- [ ] Vignettes, icône, description, vérification d'identité, maturité, passage en public : réservé au propriétaire.
- [ ] Optionnel : ElevenLabs (clé) pour les voix ; son licence à vérifier.
