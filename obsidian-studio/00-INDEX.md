## Comment l'utiliser (économie de tokens)
1. Lire cet index (court).
2. Ouvrir une seule note ciblée.
3. Si un fait manque, le chercher dans le dépôt (code, CHANGELOG du jeu), puis l'ajouter ici.
4. Ne jamais relire les conversations : tout ce qui compte doit être ici.
