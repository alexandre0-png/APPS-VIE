L'Affaire du Coffre

Un vieux journal du maire a été retrouvé : il cache le code d'un coffre oublié. Quatre énigmes mènent à quatre chiffres.

Énigme 1 · La Banque

« Là où l'argent dort sous des colonnes de marbre, le premier chiffre veille. »

Énigme 2 · La station de taxi

« Les roues attendent, les clients patientent : le deuxième chiffre est jaune comme un taxi. »

Énigme 3

« On y cuit la pâte avant de la livrer : le troisième chiffre sent bon. »

Rends-toi sur place (à pied ou en voiture) : le chiffre apparaît tout seul. Quand les 4 chiffres sont réunis, entre le code pour ouvrir le coffre (8 000 $ + 300 XP).

Animations du journal

Les chiffres « tombent » en place avec un rebond, l'énigme s'écrit lettre par lettre. Le coffre ouvert débloque le succès « Détective de la ville ».
