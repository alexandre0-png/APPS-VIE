Chipe-Œufs : maquette visuelle

Maquette des écrans du jeu Roblox. Les noms, textes, prix et valeurs sont lus dans Config.lua (fichier généré par roblox/tools/make_mockup.py). C'est une illustration : le rendu réel (3D, UI Roblox) est à voir dans Studio.

Fichier unique et autonome : aucune ressource externe. Les 5 œufs montrent l'apparence construite par le code (Config.EggFx) ; les modèles Roblox listés dans Config.Assets les remplacent quand ils se chargent.
