8. Journal des énigmes

Étapes de la chaîne principale, dans l'ordre du code (Quests.lua).

  1. Rassembler trois souvenirsUne lampe aide à les voir dans le noir.
  2. Trouver le code caché dans la maisonUn papier froissé se cache sur une surface plate, près d'un meuble.
  3. Lire les deux derniers chiffres dans un miroirUn miroir de la maison garde la fin du code. Le texte y est écrit à l'envers.
  4. Ouvrir le coffret à bijouxLe coffret à bijoux est posé sur la table de la salle de la tombe.
  5. Ouvrir la malle du grenierLa petite clé du coffret ouvre une serrure.
  6. Rejouer la mélodie du gramophoneLe gramophone du premier étage joue trois notes. Rejoue-les sur la boîte à musique.
  7. Régler l'horloge du hallUne date est gravée sur la plaque du cercueil.
  8. Prendre la clé rouillée dans la malle
  9. Les trois statues regardent la même directionLa lampe UV montre la cible de deux d'entre elles.
  10. Sortir : la porte d'entrée, ou la tombeLis les documents avant de choisir.
